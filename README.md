# Scrunch Ji — Shopify Website Proposal

A single-page, fully responsive **client proposal website** to design, build and launch a
complete Shopify e-commerce store for **Scrunch Ji** on the free **Ritual** theme — configured
for selling in **India and internationally**, delivered on a **5-day timeline**.

🔗 **Live site:** _enabled via GitHub Pages — see the repo's Pages settings for the URL._

## What's inside
- **Brand understanding** — Scrunch Ji's truck-art identity, colours and type reflected in the design
- **Scope & deliverables** — a full, revenue-ready store (homepage, catalogue, cart, checkout, content, SEO, launch)
- **India + Global readiness** — payments (UPI/cards/COD + PayPal/multi-currency), shipping, GST, taxes, compliance
- **Apps & tech stack** — a lean, mostly-free toolkit
- **5-day plan** — day-by-day delivery schedule
- **Investment** — three one-time packages (₹ + USD) and a transparent ongoing-cost table
- **Process & terms** — milestones, what's needed from the client, payment & support terms

## Tech
Hand-coded static site — HTML + CSS (no build step). Google Fonts (Poppins + Rye).
Brand colours: `#EC2A7B` · `#FFDA00` · `#2F3191` · `#000000`.

```
index.html                 # the proposal (open in any browser)
assets/                    # logo wordmark, scrunchie motif, favicons (extracted from the brand guide)
brand/Scrunchji_Brand_Guide.pdf
```

## View locally
Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8080
# then visit http://localhost:8080
```

## Send to client
Share the GitHub Pages link, or let the client open the site and use **“Save as PDF”**
(top-right) — print styles produce a clean PDF of the full proposal.
